# AgentRig 0.1.8

## Highlights

- Redesign the task-flow graph in the UI.
  - Flat DaisyUI nodes show the ID, the title, the status, the agent, the
    priority, and the handoff count.
  - Drag to pan. Press Ctrl or Cmd and use the wheel to zoom. Use Fit to
    show the whole graph.
  - Lineage focus highlights the ancestors and descendants of a task.
  - Long dependency edges run in lanes around the cards, so every edge stays
    visible.
- Add graph search and status and agent filters.
- Add compact done nodes and a Collapse done toggle.
- Open task details in a side panel beside the graph on wide screens. Narrow
  screens keep the modal drawer.
- Redesign the handoff timeline with status-colored nodes, sender and recipient
  chips, a message preview, relative time, and CSS-only motion. The motion
  stops when the user asks for reduced motion.
- Upgrade `better-sqlite3` to 13 to fix a native crash on Node 24. See ADR
  0008.
- Require Node 22 or newer. Node 20 is no longer supported.

## Upgrade notes

- Install Node 22 or newer before you upgrade.
- The `agent-rig doctor` command now checks for Node 22.
