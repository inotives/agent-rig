# AgentRig 0.2.0

This release changes the task execution workflow. The planner now runs the
worker and reviewer directly in the deployed project workspace.

## Highlights

- Replaced the wrapper-driven task loop with a planner-managed worker and
  reviewer flow.
- Made the planner the only role that changes task status, dependencies, and
  handoff records. Workers and reviewers return handoff content to the planner.
- Added read-only task prompts, task editing, and planner repair commands.
- Added a planner commit gate between completed tasks.
- Deprecated `agent-rig loop` for engineering task execution.
- Added deployment upgrade support for managed AgentRig instructions while
  preserving project-local skills, tools, configuration, and workflow data.
- Documented provider execution, handoff, and context-loading guidance for
  deployed project workspaces.

## Upgrade notes

Run `agent-rig upgrade --dry-run` from the deployed project root to review the
planned instruction updates. Then run `agent-rig upgrade` to apply them. The
upgrade creates a backup and does not launch agents.

Use the planner-managed worker/reviewer workflow for engineering tasks. Do not
start nested AgentRig loops from worker or reviewer sessions.
