# AgentRig 0.1.9

## Highlights

- Add a landing page to the UI.
  - The page shows each phase as a card with a state badge, a progress bar,
    status chips, the last update time, and a Detail button.
  - The grid has four columns, a search box, and a date-range filter. The date
    filter uses the local day of the update time.
- Change the task board into a phase view.
  - The board loads only the tasks of one phase.
  - A breadcrumb header shows "All phases / Phase N".
  - The phase dropdown and the all-phases board are removed.
  - The URLs `#/`, `#/?phase=<phase>`, and `#/tasks/<id>?phase=<phase>` work.
    A task link without `?phase=` reads the phase of the task first.
- Show an "N external" marker on tasks that depend on tasks in other phases.
  The task panel lists these dependencies.
- Add `GET /api/phases` for phase summaries. Add a `phase` query to
  `GET /api/workflow`. An unknown phase returns `404`.
- Add the sandbox runner `.agent-rig/_shared/tools/sandbox-run.sh` and the
  safe-operations rules in the profile templates and the generated
  instructions.
- Change the Claude launcher to use role-scoped permissions.
- Add a safe live Claude smoke test script (`scripts/live-claude-smoke.mjs`).
- Make the planner, worker, and reviewer loop contract more stable.

## Upgrade notes

- Run `agent-rig init` again, or follow `docs/upgrade-existing-deployment.md`,
  to get the new profile templates, the safe-operations rules, and the sandbox
  runner in an existing project.
- The all-phases board and the phase dropdown no longer exist. Use the landing
  page to select a phase.
