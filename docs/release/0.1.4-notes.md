# AgentRig v0.1.4

## Highlights

- Adds pluggable SQLite workflow storage for tasks and worker/reviewer handoffs.
- Adds a read-only task board with phase filtering, task details, searchable handoffs, and light/dark themes.
- Adds an SPA task-flow canvas with dependency arrows, status rails, zoom/fit controls, hash routing, and responsive task details.
- Adds an accessible handoff detail modal and hover previews anchored to the hovered task card.
