# Summary

Implemented task and loop routing through the active workflow store.

- `status` and `start` inspection now obtain tasks and handoffs through the
  store, including SQLite logical project/task/sequence identity.
- Markdown handoff compatibility remains chronological and ignores unrelated
  files; malformed legacy handoffs are represented without failing status.
- Loop prompts identify the project and task ID and direct mutations through
  `agent-rig tasks ...`; they no longer require a canonical task file path.
- SQLite loop transitions use `updateTaskWithHandoff` when available so the
  task update and handoff append share the store transaction. Markdown keeps
  its existing sequential adapter behavior.
- The workflow-store contract now exposes `listAllHandoffs` for backend-neutral
  status and resume inspection.
