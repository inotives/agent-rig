# Task

## Context

Phase 17 needs a simple local kanban board built with vanilla TypeScript and
Tailwind CSS, without a frontend framework.


## Goal

Build the packaged board shell that displays all six task status columns and
supports phase filtering, responsive layout, and theme switching.


## Scope

- Tailwind CLI input/build integration and packaged CSS asset.
- Vanilla TypeScript board rendering and API client.
- Fixed columns: todo, ready, in_progress, blocked, review, done.
- Phase dropdown with All phases, canonical/inferred phases, and Unassigned.
- Priority then most-recently-updated card ordering.
- System theme default with persisted light/dark preference.
- Loading, empty, retry/error, and last-good-data states.

## Acceptance Criteria

- [ ] Board renders task cards in the six agreed columns.
- [ ] Phase filtering leaves all status columns visible.
- [ ] Cards show ID, title, priority, assignee, phase, updated time, and
      handoff count.
- [ ] Tailwind assets are generated by the normal build and require no
      runtime download.
- [ ] Theme preference persists and applies to the board.
